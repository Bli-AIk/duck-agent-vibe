# Duck Agent

Duck is a Pi coding-agent extension for developers who want an AI to explain,
question, and inspect without taking ownership of project changes.

The current version is deliberately read-first:

- project mutations from Agent tools are blocked by default;
- ordinary requests to modify files are refused by the model unless the developer explicitly acknowledges and insists;
- ordinary assistant code text is still visible;
- read-only tools and explicitly configured diagnostics remain available;
- file changes are batched and scored before Duck asks anything;
- questions are generated by an isolated, tool-less model call;
- supervision is on by default and can be toggled for the current session.

## Local checks

This project does not require Pi to be installed globally. Dependencies are
local to this directory.

```bash
npm run check
npm test
npm run build
```

## Start Duck

From this directory:

```bash
./start.sh
```

The script prefers the project-local Pi CLI, falls back to an existing `pi`
on `PATH`, and otherwise installs dependencies locally without sudo. Extra
arguments are passed to Pi, for example `./start.sh --no-session`.

The launcher first uses the active custom provider in
`~/.codex/config.toml` (`model`, `base_url`, and `wire_api`) when available.
It falls back to `/tmp/info.txt`, which supports JSON fields such as `baseUrl`
and `model`, `key=value`/`key: value` lines, or two plain lines containing the
API URL and model name. `/tmp/key.txt` is configured as Pi's request-time API
key source. The launcher never opens the key file; it is not copied into the
project or printed. Override the paths with `DUCK_AGENT_CODEX_CONFIG`,
`DUCK_AGENT_INFO_FILE`, and `DUCK_AGENT_KEY_FILE` when needed.

## Install into Pi later

After installing Pi, load this directory while developing:

```bash
pi -e /home/aik/Temps/duck-agent/src/index.ts
```

For a project-local Pi package, use Pi's package installation flow from the
directory containing this project. The package manifest already exposes
`src/index.ts` as its extension entrypoint.

## Commands

Inside Pi:

- `/duck on` enables active supervision for the session.
- `/duck off` disables watching and proactive questions but keeps mutation blocking.
- `/duck ask` requests one question immediately.
- `/duck accept` publishes a pending question to the conversation.
- `/duck dismiss` clears a pending question.

The default shortcut is `Ctrl+Shift+D`. It toggles supervision for the current
session.

## Project configuration

Pi continues to load `AGENTS.md` or `CLAUDE.md` as natural-language project
context. Add `.duck.toml` only for machine-readable thresholds, diagnostics,
ignore rules, or a supervisor model override. See `.duck.toml.example`.

The audit log is kept outside the project at
`~/.local/state/duck-agent/` so Duck does not create project files itself.
